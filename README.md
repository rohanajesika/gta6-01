Solmar Bay is an open-world crime game in the browser: explore a sun-soaked coastal city on foot and by car, steal cars, outrun Bay PD as your wanted level climbs, and run jobs for fixer Mara Voss. Built with three.js — the city, traffic, pedestrians, police chases, missions, combat, HUD with live minimap, start screen, pause menu and saves are all in the game itself, with no network request at play time.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD to move and drive, mouse drag to look around, E to steal and enter a car, F to shoot, P to pause and save, M to mute.
